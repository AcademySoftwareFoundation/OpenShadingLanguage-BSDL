Contributing to BSDL
====================

Code contributions to BSDL are always welcome. 

BSDL is a secondary repo of the Open Shading Language project and follows
all governance and contributing policies of OSL.

Please see the [contribution guidelines of OSL](https://github.com/AcademySoftwareFoundation/OpenShadingLanguage/blob/main/CONTRIBUTING.md). There you will find information about
- Developer Certificat of Origin (DCO) -- required for this project.
- Contributor Licensing Agreement -- required for this project.
- [Policy on AI Coding Assistants](https://github.com/AcademySoftwareFoundation/OpenShadingLanguage/blob/main/docs/dev/AI_Policy.md)
